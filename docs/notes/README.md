# Zadatak: bilješke projekta

Ovo je memorija projekta. Claude ih čita prije svakog posla i dopunjava ih kad se nešto odluči ili završi.
Otvara se u Obsidianu: File > Open folder as vault > `docs/notes`.

- [[pravila]]: kako radimo, dizajn i uslovi za pokretanje
- [[odluke]]: šta je odlučeno i kada
- [[otvoreno]]: šta čeka na sd, šta čeka na Claudea

## Projekat ukratko

- Zadatak: bosanski marketplace za lokalne usluge (objavi posao, izvođači šalju ponude, plaćanje preko Balansa).
- Ranije ime Poso.ba, promijenjeno u Zadatak 04.10.2026.
- Živi sajt (beta): https://bilalishakcanada-wq.github.io/websample/
- Domena: zadatak.ba (mailovi već idu s info@zadatak.ba, sajt još nije prebačen).
- Stack: React 19 + Vite, Supabase (baza, prijava, Edge Functions), Capacitor za Android i iOS.

## Kako održavati

- Jedan fajl po temi. Kratko, samo činjenice.
- Bez izmišljenih podataka. Ako nešto nije provjereno, napiši da nije.
- Datum uz svaku odluku i svaki otvoreni zadatak (DD.MM.GGGG.).
- Kad se zadatak završi, briši ga iz [[otvoreno]] i, ako je bila odluka, upiši je u [[odluke]].
